# img-conv
Реализация свёртки изображений на Python. Сравнение производительности с OpenCV и Pillow.

## Эксперименты

Использовались ядро box_blur и тип обработки краёв constant. Тестирование проводилось для изображений размером 1024×1024, 2048×2048 и 4096×4096, отдельно для цветных изображений и изображений в оттенках серого.

Тестовые изображения генерировались с помощью NumPy и содержали случайные значения пикселей из равномерного распределения в диапазоне от 0 до 1. Тестирование проводилось с использованием pytest-benchmark.

Измерения проводились на системе со следующими характеристиками:

* Процессор: AMD Ryzen 7 8745HS w/ Radeon 780M Graphics, x86_64.
* Оперативная память: 12 ГБ.
* Операционная система: Ubuntu 24.04.4 LTS.

Измерения выполнялись в режиме performance. Пользовательские приложения были отключены для уменьшения влияния фоновых процессов.

## Запуск экспериментов

Бенчмарки запускаются с помощью pytest. Полученные результаты сохраняются в JSON-файл:

pytest src/benchmarks/test_benchmark.py \
  --benchmark-warmup=on \
  --benchmark-json=src/benchmarks/data/benchmark_raw.json

В команде используются два параметра pytest-benchmark:

--benchmark-warmup=on включает предварительный прогрев перед измерением. Прогрев позволяет выполнить тестируемую функцию до начала измерения и уменьшить влияние начальных затрат выполнения.
--benchmark-json=src/benchmarks/data/benchmark_raw.json сохраняет результаты измерений в JSON-файл. Этот параметр не изменяет само измерение, нужен для последующей обработки результатов.

## Обработка результатов и построение графиков

После завершения бенчмарков результаты из JSON обрабатываются с помощью:

python -m src.benchmarks.execute

Скрипт execute.py читает файл:

src/benchmarks/data/benchmark_raw.json

После обработки создаются:

src/benchmarks/data/results.json
src/benchmarks/images/color_performance.png
src/benchmarks/images/grayscale_performance.png
src/benchmarks/images/speedup.png

В results.json сохраняются среднее время выполнения, стандартное отклонение, отношение времени авторской реализации к OpenCV и Pillow, а также результаты проверки статистической значимости различий.

Графики строятся на основе уже обработанных данных из results.json. Они показывают время выполнения свёртки для цветных изображений(color_performance.png) и изображений в оттенках серого(grayscale_performance.png), а также отношение времени выполнения авторской реализации ко времени выполнения библиотечных реализаций(speedup.png).

## Выводы

Время выполнения всех трёх реализаций имеет линейную зависимость от количества пикселей при фиксированном размере ядра. При увеличении стороны изображения в два раза количество пикселей увеличивается в четыре раза, и время обработки также увеличивается примерно в четыре раза.

Авторская реализация значительно медленнее библиотечных реализаций. По результатам экспериментов её время выполнения больше времени OpenCV примерно в 1194-29800 раз, а Pillow примерно в 337-537 раза.

Различие связано с реализацией вычислений. В авторской реализации свёртка выполняется с помощью трёх вложенных циклов на Python. OpenCV и Pillow используют оптимизированные низкоуровневые реализации, поэтому обработка выполняется значительно быстрее.
